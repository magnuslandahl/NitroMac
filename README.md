# NitroMac

NitroMac is a menu-bar toolbox for macOS 15 and later on Intel and Apple silicon Macs.

[Download NitroMac for Mac](https://github.com/magnuslandahl/NitroMac/releases/latest/download/NitroMac.dmg)

Open the disk image and drag **NitroMac.app** to **Applications**. Rabamba AB signs the app with Developer ID. Once installed, open the NitroMac menu, choose the settings gear, and select **Check for Updates…**.
